# Gremlin (gremlin)

Gremlin is a chaos engineering platform that helps teams build more resilient systems by running controlled failure experiments. It provides tools to simulate infrastructure failures, network issues, and resource exhaustion to identify and fix weaknesses before they cause real outages.

**APIs.json:** [https://www.gremlin.com](https://www.gremlin.com)

## APIs

### Gremlin API

The Gremlin Failure-as-a-Service API for programmatically running chaos engineering attacks, scenarios, reliability tests, disaster recovery experiments, and managing teams, integrations, and infrastructure targets across cloud, container, and Kubernetes environments.
